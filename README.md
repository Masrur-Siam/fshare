# ⚡ FSHARE — Instant P2P Asset Transfer

**FSHARE** is a modern, ultra-fast, browser-to-browser file sharing web application built using **WebRTC**. It works entirely peer-to-peer (P2P) without requiring any central database or cloud storage limits.

🌐 **Live Demo:** [masrur-siam.github.io/fshare](https://masrur-siam.github.io/fshare)

---

### ✨ Key Features

* **🚀 Zero Database & Cloud Storage:** Files never touch a server. They stream directly from browser to browser.
* **📦 Unlimited File Sizes:** Share single or multiple files (videos, APKs, apps, zips, archives) of any size.
* **🔑 6-Digit Secure Passcode:** Automatic random passcode and high-contrast QR Code generation for instant node pairing.
* **⚡ High-Speed Stream:** Optimized 256 KB chunks with unthrottled WebRTC data channels for maximum network velocity.
* **💎 Ultra-Glassmorphic UI:** Modern dark sci-fi theme built with Tailwind CSS, animated waveforms, and interactive panels.

---

### 🛠️ Tech Stack

* **Frontend:** HTML5, JavaScript (ES6+)
* **Styling:** Tailwind CSS, Google Fonts (Orbitron & Plus Jakarta Sans)
* **Networking:** PeerJS (WebRTC Wrapper for signaling and P2P data channels)
* **Icons & Utilities:** Lucide Icons, QRCode.js

---

### 💻 How It Works

1. **Transfer (Sender):** 
   * Open the app and select/drop one or multiple files.
   * A unique 6-digit access code and QR code will instantly generate.
   * Share the code or QR with the receiver.
2. **Receive (Receiver):**
   * Enter the 6-digit code or scan the QR code on any device anywhere in the world.
   * Accept the direct connection stream and download the file instantly.
